# Expense Tracker – Frontend (Angular 17)

See the project [README](../README.md) and the detailed guide in [docs/HOW-IT-WORKS.md](../docs/HOW-IT-WORKS.md).

```bash
npm install
npm start            # ng serve on http://localhost:4302, /api proxied to http://localhost:8082
npm test             # Karma + Jasmine unit tests
npx ng build         # production build into dist/frontend/browser
```
